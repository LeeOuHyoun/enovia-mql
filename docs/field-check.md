## 0.0.24 변경 · 문법 색칠

입력창과 기록의 명령 문장에 문법 색을 넣었습니다. 입력창은 글자를 투명하게 하고, 같은 위치에 색칠한 글자를 겹쳐 그립니다. 헤드리스 브라우저로만 확인했습니다.

- [ ] ⚠️ 입력창에 입력하면 명령어(temp · print · mod …)는 보라, 키워드(bus · select · where …)는 파랑, 따옴표 값은 주황, ID · 숫자는 연두, `attribute[…]` 같은 select 식은 청록, 템플릿의 `<…>` 칸은 노랑 점선으로 보인다 (테마마다 색은 다를 수 있음)
- [ ] ⚠️ 커서 위치 · 글자 선택 · 한글 입력(조합 중 글자 포함)이 글자와 어긋나지 않는다. 긴 줄이 접혀도 어긋나지 않는다
- [ ] 줄 번호를 켜거나 끄고, 입력창을 스크롤하고, 창 크기를 바꿔도 색칠한 글자가 제자리에 있다
- [ ] 기록 블록 머리의 명령 문장도 같은 색으로 보인다. 결과 검색(Ctrl+F) 중에는 예전처럼 검색 강조가 보인다
- [ ] 2만 자가 넘는 긴 스크립트를 붙여 넣으면 색칠 없이 예전처럼 보이고 입력이 느려지지 않는다
- [ ] 다크 · 라이트 · 고대비 테마에서 글자가 읽힌다

## 1. MQL 문법 · 출력 형식 사전 확인

MQL 콘솔에서 직접 실행합니다. 결과가 설명과 다르면 `피드백:`에 실제 출력을 붙여 주세요. 괄호 안은 그 형식에 기대는 기능입니다.

- [ ] ⚠️ `print context;` 출력이 `context vault <vault> user <user>` 꼴이다 (상단 접속 표시)
- [ ] ⚠️ `print attribute '<속성>' select name type default range;` 를 여러 줄 한꺼번에 보내면 속성마다 `name = <속성>` 줄이 먼저 나오고, 그 아래에 `type =` · `default =` · `range =` 줄이 나온다 (속성 정보 한 번에 조회)
- [ ] ⚠️ 위처럼 보낸 속성 중 하나가 없어서 오류가 나도, 나머지 속성의 결과는 그대로 나온다
- [ ] ⚠️ `print bus <id> select description;` 에서 여러 줄 값의 둘째 줄부터가 `description =` 아래 줄로 이어져 나온다 (편집 패널의 여러 줄 값)
- [ ] ⚠️ `mod bus <id> description 'line1<줄바꿈>line2';` 처럼 따옴표 안에 줄바꿈이 든 문장이 줄바꿈을 지킨 채 저장된다 (편집 패널 저장)
- [ ] `print type '<Type>' select abstract;` 가 `abstract = TRUE` 또는 `FALSE` 로, `print type '<Type>' select derived;` 가 `derived = <부모 type>` 으로 나온다 (생성 패널 경고)
- [ ] `temp query bus '<Type>' '<Name>' '<Rev>' select id dump '|~|';` 가 `Type|~|Name|~|Rev|~|id` 꼴로 나온다 (같은 Type · Name · Revision 경고)
- [ ] ⚠️ `list property on program eServiceSchemaVariableMapping.tcl;` 의 각 줄이 `<심볼릭> on program eServiceSchemaVariableMapping.tcl to <종류> <이름>` 꼴이다 (심볼릭 등록 안내, list 패널의 심볼릭 표시)
- [ ] ⚠️ `help clear` 로 `clear vault` · `clear all` 이 볼트 안의 객체를 지우는 명령인지 확인한다 (실행 전 확인 창 대상)
- [ ] 이름에 작은따옴표가 든 type 을 `print type "It's" select policy attribute;` 처럼 큰따옴표로 감싸도 조회된다 (따옴표 처리)

## 3. 결과 보기 · 입력

- [ ] 결과 블록 머리에 걸린 시간(`ms` · `s`)이 보인다
- [ ] 블록의 `편집기로 열기` 아이콘을 누르면 결과가 옆 편집기에 새 문서로 열린다. 표 보기 상태면 TSV 로 열린다
- [ ] 결과(텍스트 · 표)의 객체 ID 에 점선 밑줄이 있고, 누르면 `print bus 실행` · `expand bus 입력` · `객체 편집` · `복사` 메뉴가 뜬다
- [ ] 결과 찾기로 ID 의 일부를 찾아도 그 ID 를 눌러 메뉴를 열 수 있다
- [ ] 위쪽 결과를 읽는 중에는 새 출력이 와도 화면이 내려가지 않고, 맨 아래에 있으면 따라 내려간다. 새 명령을 실행하면 맨 아래로 간다
- [ ] ⚠️ 입력창에서 `Ctrl+↑` / `Ctrl+↓` 가 VS Code 에 가로채이지 않고 이전 · 다음 명령을 불러오며, 끝까지 내리면 입력하던 글로 돌아온다
- [ ] ⚠️ `mod type <Type> add attribute <A> remove attribute <B>;` 를 `Ctrl+Shift+F` 로 포매팅한 뒤 둘째 · 셋째 줄에서 `Ctrl+Enter` 를 눌러도 문장 전체가 실행된다 (전에는 `add attribute …` 줄만 실행됐음)
- [ ] `add policy` 템플릿을 포매팅한 뒤 `version` · `promote` 줄에서 `Ctrl+Enter` 를 눌러도 문장 전체가 실행된다
- [ ] `Ctrl+Shift+F` 를 여러 번 눌러도 결과가 처음 포매팅한 것과 같다
- [ ] 줄을 바꿔 쓴 서로 다른 문장(`print bus <id1>` 다음 줄에 `print bus <id2>`)은 지금처럼 커서가 있는 문장만 실행된다

- [ ] 속성이 많은 type 을 골라도 속성 칸이 전보다 빨리 나오고, 그동안 콘솔 입력이 잠기는 시간이 짧다
- [ ] ⚠️ 그리드 모드에서 여러 행을 실행하면 행 번호 옆에 ✓ · ✗ 가 붙고 첫 오류에서 멈춘다. 고쳐서 다시 실행하면 실패한 행부터 실행하고, ✓ 행은 다시 만들지 않는다
- [ ] ✓ 행의 값을 고치면 표시가 사라지고 다시 실행 대상이 된다
- [ ] 값에 작은따옴표와 큰따옴표를 함께 넣으면 경고가 나오고 실행이 막힌다

## 6. 편집 패널

- [ ] ⚠️ 여러 줄 Description(또는 속성)이 여러 줄 입력칸으로 전부 보이고, 고쳐 저장하면 줄바꿈이 유지된다
- [ ] 바꾼 칸의 이름과 테두리가 주황색이 되고, 미리보기 아래에 `되돌리는 문장` 이 보인다. `복사` 버튼이 동작한다
- [ ] 저장이 끝나면 그 블록 아래에 `되돌리는 문장` 안내가 붙고, `입력창에 넣기` 로 입력창에 들어간다
- [ ] State 옆 `promote` · `demote` 버튼의 툴팁에 다음 · 이전 state 가 보이고, 마지막 · 첫 state 에서는 막힌다. 실행 전에 확인 창이 뜨고, 실행 뒤 편집 패널이 새로 읽힌다
- [ ] 삭제가 끝나면 `다시 만드는 문장 (ID·이력·연결은 복원되지 않음)` 안내가 붙는다
- [ ] 원래 값에 작은따옴표와 큰따옴표가 함께 든 항목은 되돌리는 문장에서 빠지고 그 사실이 경고로 나온다

## 7. 심볼릭 이름 · 3D MQL 연동

- [ ] `add type` 등으로 만든 뒤, 같은 이름의 심볼릭이 이미 등록돼 있으면 `심볼릭 등록` 안내가 나오지 않는다
- [ ] list 패널에서 type · attribute 등을 조회하면 이름 옆에 심볼릭 이름이 흐리게 보인다
- [ ] ⚠️ 결과의 Object ID 링크를 **오른쪽 클릭**하면 ID 메뉴(print bus · expand · 객체 편집 · 3D MQL에서 검색)가 열린다. 왼쪽 클릭으로는 메뉴가 열리지 않고, 마우스를 올리면 커서가 메뉴 모양으로 바뀐다
- [ ] ⚠️ 결과나 MQL 문에서 공백으로 나뉜 1~3 단어를 드래그 선택하고 오른쪽 클릭하면 `3D MQL에서 검색 (Type · Name · Rev)` 가 보인다. 4 단어 이상이면 보이지 않는다
- [ ] `"Part" "P-001" "A";` 처럼 따옴표 · 끝의 `;` 가 붙은 채로 선택해도 메뉴에는 `Part · P-001 · A` 로 보인다
- [ ] ⚠️ 누르면 3D MQL 그래프 탭이 앞으로 나오고(없으면 새로 열림) 상단 검색창 Type · Name · Rev 에 값이 들어가 바로 검색된다. Object ID 하나면 그 객체가 바로 그래프로 열린다
- [ ] 3D MQL Graph 확장(0.0.25 이상)이 설치된 창에서만 그 메뉴가 보인다
